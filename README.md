# PHP Framework

Framework PHP minimalista e moderno para construção de aplicações web.

## Requisitos

- PHP 8.0+
- Servidor web (Apache/Nginx) ou PHP built-in server
- Git

## Instalação Rápida (para usar como base)

```bash
# 1. Clone o repositório
git clone https://github.com/anthonybr423/php-default-mvp.git seu-projeto

# 2. Entre na pasta
cd seu-projeto

# 4. Inicie seu próprio repositório Git
git init
git add .
git commit -m "Initial commit: Baseado em PHP Framework"
git branch -M main

# 5. Adicione seu repositório no GitHub e envie
git remote add origin https://github.com/SEU-USUARIO/seu-projeto.git
git push -u origin main
